## #1 Claude モデルの追加と二段階価格（CR wp36-1）
- contract: `packages/core/src/domain.ts` — `ClaudeModelId` に `claude-haiku-5-5`・`claude-fable-5-1` を追加（`claude-haiku-4-5` は残す）。一覧の正本 `CLAUDE_MODEL_IDS` を新設し、settings の `MODEL` 正規表現・`setup claude --model` 許可リスト・Web のモデル選択肢・`--help`・README はそこから作る。`ModelPrice` に任意の `longContext?: { overInTokens; price }` を追加。`PRICING_VERSION` は `"2026-11-03"`。
- change: `PRICING` を公式価格（https://platform.claude.com/docs/en/about-claude/pricing 、2026-11-03 確認）に合わせる。fable-5-1（in 10 / 5m 12.5 / 1h 20 / read 0.25 / out 50、prefix 512、v5）、opus-5-5（変更なし、read 0.20 のまま）、sonnet-5-5（cache read 0.2→**0.10** の誤り修正）、haiku-5-5（100,000 token 以下: in 0.10 / 5m 0.125 / 1h 0.20 / read 0.01 / out 0.50、上段: in 0.50 / 5m 0.625 / 1h 1 / read 0.05 / out 2.50）、haiku-4-5（変更なし、prefix 4096、v4）。`priceUsage` は1リクエストの入力（uncached + cache read + cache write）が閾値を超えたら上段を全項目に使う。`outTokPerSec` は fable 50・haiku-5-5 150 の仮値（実行時に校正）。
- why: Orca の一覧にある haiku-5-5・fable-5-1 が settings・setup・PRICING で拒否されていた。sonnet の cache read は公式と食い違っていた。
- tests: `packages/core/src/pricing.test.ts`（WP36-A。二段階の境界・全項目の上段適用・一覧と PRICING の一致）、`packages/agent/src/claude/spawn.test.ts`（WP36-A。新 id の `--model` 通過と別名の拒否）、`packages/server/src/settings/settings.test.ts`（WP36-A/D。役割モデルと grok-cli 設定の検証）、`apps/cli/src/commands/setup.test.ts`（WP36-A。setup の許可）。

## #2 Codex の effort とモデル別価格（CR wp36-2）
- contract: `EngineSettings["codex-cli"]` に任意の `pricingByModel?: Record<string, 価格3項目>` を追加。見つからないモデルは `pricing`、それも無ければ従来どおり起動前に拒否（上限予約ではなく拒否のまま。native thinking は hard cap できないため）。
- change: `codexCatalog(model, agent, effort)` が `default_reasoning_level` に要求の effort を入れる（`-c model_reasoning_effort=<e>` は従来どおり。`codex exec --help` に `--effort` flag は無い）。engine・gen は `codexPricing(settings, slug)`（`pricingByModel[slug] ?? pricing`）で事前判定と terminal 使用量を付ける。`ultra` は mitori の `ReasoningEffort` に無いため対象外。setup の Codex native 既定価格に `gpt-5.6-terra`（in 2 / out 12 / read 0.2）・`gpt-5.6-luna`（in 0.20 / out 1.20 / read 0.02、2026-07-30 改定 https://openai.com/blog/advancing-the-price-performance-frontier-with-gpt-5-6 、cache read は in の 0.1 倍）を追加し、選ばれなかった方の既定価格も `pricingByModel` に残す。`gpt-6-luna` は公式価格が無いため既定価格なし。
- why: catalog の `default_reasoning_level` が `low` 固定で、settings の `reasoning.*` が codex に届いていなかった。Orca の一覧にある 5.6 系2モデルに単価が無かった。
- tests: `packages/agent/src/adapters/adapters.test.ts`（WP36-B。`-c` と catalog の effort・`codexPricing` の優先順）、`packages/agent/src/adapters/codex-engine.test.ts`（WP36-B。要求モデル別の使用量単価と fallback）、`apps/cli/src/commands/setup.test.ts`（WP36-B。5.6 既定価格）。

## #3 Grok Build CLI エンジンの新設（CR wp36-3）
- contract: `EngineId` に `grok-cli`、`ModelId` に `` `grok:${string}` `` を追加。settings に `"grok-cli": { enabled, binary, model, pricing?, pricingByModel?, turnMs? }`（既定 `enabled: false, binary: "grok"`）。`dataPolicyAck`・`pins` のキーに `grok` を追加。
- change: `packages/agent/src/adapters/grok-policy.ts`（単発 spawn ビルダーと streaming-json fold）・`grok-engine.ts`（detect/run）・bridge 配線。起動は `--prompt-file`（stdin 空）・`--output-format streaming-json`・`-m`・`--reasoning-effort`・`--max-turns 1`・`--no-subagents`・`--no-plan`・`--disable-web-search`・`--disallowed-tools` 全列挙・`--cwd {emptyCwd}`・`--verbatim`・`--leader-socket {隔離root}/leader.sock`（`--always-approve`・bypass 不使用）。Muse（ADR-0015 §4）と同じ考え方で、mitori home 内の呼び出しごと専用 `GROK_HOME`（`GROK_HOME` が `~/.grok` を上書きする。バイナリ内蔵 headless 文書と `leader.sock`・`GROK_LEADER_SOCKET` の記述で確認）を SafeWriter で作り、空の `config.toml` と認証ファイルだけを regular/non-symlink 確認つきでコピーし、終了・失敗・キャンセルで消す。回答・生成（テキストと既存 JSON 抽出）のみで、agent / patch モードと tool request は拒否。出力 JSON から本文・usage・tool 実行痕跡を読み、tool 実行は失敗、usage 欠落は generic と同じ byte 推計（`usageEstimated: true`）。detect は `--version` と `grok models`（未ログインは "You are not authenticated."、LLM を呼ばない）で、未ログインなら `grok login` を案内。`setup grok --cli [--model grok-4.7]`（既存 preset 価格 in 2 / out 6 / read 2、他モデルは価格指定を要求）。他のモデルの上限予約は generic と同じ扱い。
- why: Grok を使う engine が無く、HTTP の xAI API か手順コピーしか無かった。
- 制限: 実 grok 呼び出しは未実行（fake 子プロセスと cassette のみ。作業時は未ログイン）。`--json-schema` の実機受理・`streaming-json` の event 名・`grok models` の未ログイン文面の実機確認は残る。
- tests: `packages/agent/src/adapters/grok-policy.test.ts`・`grok-engine.test.ts`（WP36-C。argv・隔離・tool 検知・未ログイン・価格予約）、`apps/cli/src/commands/setup.test.ts`（WP36-C。preset）、`apps/web/src/settings/provider.test.ts`（WP36-C。接続コマンド）。
