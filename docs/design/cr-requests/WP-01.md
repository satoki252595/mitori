## `GitReader`: say what untracked entries and `statusDirty` contain
- contract: `packages/core/src/domain.ts` §18 `GitReader.lsFiles` / `statusDirty` (doc comments only)
- change: `lsFiles()` untracked entries (`tracked: false`) carry `blob: ""` and `mode: ""` (the indexer hashes them, indexer
  spec §2.1). `statusDirty()` = every non-ignored path porcelain v2 reports (`--untracked-files=all --no-renames`):
  worktree changes, staged-only changes (`M.`, `A.`, `D.`), unmerged and untracked paths.
- why: the comment lists the categories but not the untracked blob; the indexer's "dirty = Y≠. or u" is a subset it can
  filter with `status()` (which returns `xy`).
- workaround in place: implemented as above (`packages/platform/src/git/reader.ts`).
- urgency: nice to have (WP-02 reads it).
