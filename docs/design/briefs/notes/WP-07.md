  gen's Verifier), `linemap/` (Myers), `engine/` (`createAnchorEngine({ hasher })`). anchor depends on core only:

  later versions are appended by the S6 stream). The `ReviewEngine` factory is reached through `createLoop`
  (stub in `jobs/`, WP-08b) — build yours in `review/` and let 08b compose it.
- State machines: use core `canTransition` / `assertTransition` / `threadTransition` (`E_STATE_TRANSITION`, agents
  can never resolve) instead of re-encoding `THREAD_TRANSITIONS`.
- Mutations happen only inside the workspace `write()` queue (WriteQueue port); `wait` waiters count for the
  daemon's idle logic.
