  rate-limit, max-budget — see its README); cassettes `fixtures/cassettes/<suite>/` (`mitori.cassette/1`,

  dispatches to `bench/contract/run.ts` once you create it).

## Notes (M0 layout)

- Sub-directories: `claude/` (`buildClaudeSpawn`, `claudeUserMessage`, `editPermissionRule`, `agentPathsOk`),
  `normalize/` (`createClaudeNormalizer`, `usageFromClaudeResult`), `usage/` (`createUsageMeter`; `priceUsage` is
  **core's** implementation re-exported — CORE-U-004 tests it), `adapters/` (codex/generic/anthropic builders,
  `extractJsonFromText`), `bridge/` (`createAgentBridge`, `AGENT_MIGRATIONS` for `use_*` in state.sqlite),
  `scheduler/` and `ledger/` (internal parts of the bridge).
- The `Spawner`/`SpawnSpec`/`ChildHandle` port is declared in this contract (B4) and implemented by platform
  (WP-01) structurally; you consume it via deps. Tests use a replay Spawner over the recordings — the shared one
  (`createReplaySpawner` etc.) is a testkit stub today; build `src/testing.ts` (`@mitori/agent/testing`) with the
  testkit contract §5 shapes and the testkit will re-export it (CR m0-6).
- Invariants I1–I14 are data in the contract (`CLAUDE_CLI_INVARIANTS`); every test id AGT-U-I01…I14 must fail when
  one flag is removed (mutation check).
- Session rules: no paid API calls; `claude -p` only for the maintainer-run contract job (CC-xx, tiny haiku calls,
  total < $0.05). Unit/int tests use recordings only.
