## Notes (M0 layout)

- Sub-directories: `codec/` (parse/serialize, marker form, semantic hash, claim spans, romaji, merge3;
  `canonicalJson` is **core's** implementation re-exported here — do not re-implement), `store/`
  (`createDocStore`, `DOC_MIGRATIONS`, `createAiMarkdownValidator`), `render/` (`createBlockRenderer`), `layout/`
  (`createDiagramLayouter`; `layout/floorplan.ts` is reserved for WP-18). `export/` is WP-13.
- `GenIdSource`, `NewBlockRef`, `RawCite` moved from Part B into this contract (A5, CR m0-2); `CodeSlice` is core
  (CR m0-1). doc may import only core + platform.
- No file I/O and no Bun APIs: reads via the injected `FsReader`, writes only via `SafeWriter` (kind `doc`), heavy
  work (Shiki, ELK) via injected `WorkerPool`s — use an in-thread pool in tests. Ids come from the `Random` port
  (`newId`) or deterministic `staticBlockId` / `glossaryId` (core).
- markdown-it 15 with `html: false`; Shiki 4.5 (`@shikijs/core` + oniguruma, fine-grained, css-variables theme);
  elkjs 0.12 — all pinned in `packages/doc/package.json`.
- Secret scanning of rendered/exported text uses core `createSecretScanner` (one redaction token
  `«redacted:secret»`).
