  pinned in loop — it pulls express/hono, so check the binary-size impact before importing it into the CLI path.
- CLI entry `apps/cli/src/main.ts` is WP-11a's: register commands from `commands/` and keep the top level
  import-free (lazy `await import`) to protect the 20 ms `--version` start-up.
- CLI may use `Bun.*`/`node:*` but never write files or spawn directly — through `@mitori/platform` (SafeWriter,
  Spawner); TTY-required commands fail with `E_TTY_REQUIRED` under `CLAUDECODE=1` / non-TTY.
- `integrations/` (plugin/skill/hook templates) is yours (root dir, embedded into the binary).
- `claude plugin validate` and the Pull E2E with the real Claude Code are maintainer-machine steps (tiny calls
  only; this session forbids paid API use).
