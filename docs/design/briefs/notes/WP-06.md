## Golden / truth / fixtures

- Prompt goldens `fixtures/golden/<fixture>/prompts/<promptId>.<target>.txt` (normalized with testkit
  `normalizeForKey`); plan goldens (`GenPlan` canonical JSON byte-identical, AC-01). Unit/int tests use **scenario
  cassettes** (selected by router name; prompt-hash drift only warns) — exact-key cassettes are nightly only.
- Read the indexer through fakes: testkit `indexerFromGolden(name)` (stub today — until it lands, hand-build an
  `Indexer` object returning fixed `moduleContext`/`repoPack`/`skeleton` values).

## Notes (M0 layout)

- Sub-directories: `line/` (validator, assembler, `planRetry`), `prompts/` (the 7 M2 prompts, English, versioned
  `<id>@<n>`, `GEN_DATA_FENCE`), `planner/` (effort plans, estimates, `WINDOW_PRIORS`), `verify/`
  (`computeVerdict`, `extractIdentifiers`, Verifier implementing `ClaimStamper`), `engines/`
  (`toScheduledRequest`), `session/` (`prepFingerprint`, prep/ingest), `orchestrator/` (`createGen`,
  `GEN_MIGRATIONS`). `incremental/`, `ondemand/`, `translate/` are WP-06b.
- `GenIdSource`, `NewBlockRef`, `RawCite` moved to the doc contract (CR m0-2); this contract re-exports them.
- gen ⟂ loop: never import `@mitori/loop`; cross-package reactions go through server `DOMAIN_WIRING` (WP-INT).
- **No real engine runs in this WP** (O1/O2, M-1…M-12 are measured in the M2 window, SC-02). No paid API calls.

## Out of scope

S9 incremental, on-demand, translation, the 5 M4 prompts (WP-06b); doc store internals (WP-04).
