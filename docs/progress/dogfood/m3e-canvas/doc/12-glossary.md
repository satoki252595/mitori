# 12. 用語集 <!-- b_d6m8fxdy -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| Item | あいてむ | item | フレームに置かれる部品 1 個を表す型。種類は Kind で区別される。 |
| Action | あくしょん | action | 部品のタップで起こる動作の定義。画面遷移などをプレビューで再現する。 |
| Inspector | いんすぺくたー | inspector | 選択した部品の見た目や挙動を編集するパネル。デザインと挙動のタブを持つ。 |
| Kind | かいんど | kind | 部品の種類を表す型。ボタンやチップなど、Item の形を決める。 |
| Group | ぐるーぷ | group | 複数の Item をまとめた単位。フレーム内での配置や整列の対象になる。 |
| Gesture | じぇすちゃー | gesture | パン、範囲選択、フレーム移動、グループ移動の操作状態。 |
| Snapshot | すなっぷしょっと | snapshot | グループとフレームの状態を保存する履歴の単位。元に戻す操作に使う。 |
| Spring | すぷりんぐ | spring | 形状補間の動きに使うばねの計算クラス。 |
| Theme | てーま | theme | 角丸、書体、動きなど全体の見た目設定をまとめた型。 |
| Doc | どっく | document | フレームやグループなどプロジェクト全体を表す文書データ。保存や共有リンクの対象になる。 |
| Variant | ばりあんと | variant | 部品の見た目の種類。Inspector のスタイル選択で切り替える。 |
| PanelShell | ぱねるしぇる | panel shell | ヘッダー、タブ、ロック表示を備えたパネルの外枠部品。 |
| Palette | ぱれっと | palette | M3 の色役割を持つ配色。lib/tokens.ts で定義され、色の算出は schemeFromSeed が担う。 |
| Frame | ふれーむ | frame | キャンバス上の 1 画面。複数のフレームを並べて画面遷移を設計する。 |
| Preview | ぷれびゅー | preview | 設計した画面を実際に操作して遷移を確かめる表示。 |
| Provider | ぷろばいだー | provider | AI 補助が使う事業者。claude、openai、gemini、deepseek から選ぶ。 |
| UI辞書 | ゆーあいじしょ | UI dictionary | 画面文言を言語ごとに持つ UI と、韓国語用の KO。 |
| Lang | らんぐ | language | UI の表示言語。ja、en、zh、ko の 4 種を扱う。 |
| Ripple | りっぷる | ripple | 押下位置から広がる波紋効果の状態。 |
