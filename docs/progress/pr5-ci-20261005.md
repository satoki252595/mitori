source `7a39335`では既存TypeScriptの標準solution builderへ一本化した。20個のNode compilerと独立した型情報読み込みを、同じ20project refsを辿るchecked builderに置換する。`noCheck:false` / `stopBuildOnErrors:false`、宣言生成も意味検査付き。未検査の`checkPending` cacheは意味検査へ戻し、成功済みincremental cacheだけ再利用する。ログはproject総数・実semantic builds・cachedを区別する。既存2project回帰はnoCheck-only宣言をseed→両projectのTS2322を検出→修正後成功→checked cache再利用、時間gate回帰と合わせ **2 pass / 16 assertions、0.56秒**。
