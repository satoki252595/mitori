# 12. 用語集 <!-- b_et2d5b44 -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| Item | あいてむ | item | キャンバスに置く個々の部品を表す型。種別（Kind）、見た目、挙動などを持つ。 |
| Action | あくしょん | action | 部品のタップなどで起きる挙動を表す型。遷移先のフレームなどを指定する。 |
| インスペクタ | いんすぺくた | inspector | 選択した部品の見た目と挙動を編集するパネル。デザインと挙動のタブを持つ。 |
| Kind | かいんど | kind | 部品の種別を表す型。ボタンやチップなどの種類を区別する。 |
| 共有リンク | きょうゆうりんく | share link | 文書を URL ハッシュに埋め込んだリンク。開くと同じ文書を復元できる。 |
| KIND_SPEC | きんどすぺっく | kind spec | 部品種別ごとの既定寸法やフラグをまとめた表。 |
| Group | ぐるーぷ | group | 連結または自由配置される部品の集まり。レールやタイディの整列処理はグループ単位で行う。 |
| Theme | てーま | theme | 形状、書体、モーションなど、部品全体の見た目の設定を表す型。 |
| Transition | とらんじしょん | transition | フレーム間を移動するときの遷移効果を表す型。プレビューで使われる。 |
| Doc | どっく | document | エディタが扱う文書全体を表す型。フレーム、部品、パレット、テーマなどを保持し、プロジェクトファイルや共有リンクの元になる。 |
| Variant | ばりあんと | variant | 部品のスタイルの違い（塗りや枠線など）を表す型。インスペクタで選ぶ。 |
| Palette | ぱれっと | palette | 配色トークンをまとめた型。シード色から schemeFromSeed で生成でき、各コンポーネントが色を受け取る元になる。 |
| Frame | ふれーむ | frame | 一つの画面を表す型。部品のグループを配置する領域で、プレビューでは遷移の単位になる。 |
| プロンプト | ぷろんぷと | prompt | buildPrompt が Doc から生成する、実装を AI に依頼する文章。 |
| モーフィング | もーふぃんぐ | morphing | 形状の点列を線形補間して別の形へ滑らかに変える処理。ローディング表示で使う。 |
| リプル | りぷる | ripple | 押下位置から広がる波紋の効果。 |
