# 10. 設計判断 <!-- b_0wchcn5x -->

> [!IMPORTANT]
> - **ボタンの寸法は五つの名前付きサイズの間を補間し、段階の途中の高さでも連続した値を取る。** 五つの停止点だけを選ばせる案ではなく、`BUTTON_SIZES` の隣り合う二段階を混ぜる方式を採った（[tokens.ts:8-14](../../lib/tokens.ts#L8-L14)）。理由は、スライダーが停止点以外でも M3 の形を保つためである（[tokens.ts:24-27](../../lib/tokens.ts#L24-L27)）。寸法を足すときは `onScale` の補間に乗せる必要がある。 <!-- b_6ev5pvth -->

> [!IMPORTANT]
> - **カルーセルはカード幅を箱に対する M3 のキーラインで測り、均等割りにしない。** 均等に分け合う案ではなく、行が端を越えてスクロールする形にした（[tokens.ts:702-705](../../lib/tokens.ts#L702-L705)）。停止点はどのカードでも等間隔で、手の動きに合わせて行が進む（[tokens.ts:753-760](../../lib/tokens.ts#L753-L760)）。カルーセルの寸法や位置を変える人は `cardWidths`、`carouselStops`、`carouselShapes` の整合を保つ必要がある。 <!-- b_7szkj1f1 -->

> [!IMPORTANT]
> - **実行時だけの状態は `Item` に持たせるが、JSON には書き出さない。** FAB のメニュー展開や上向き表示はシンボルキーのフィールド（`fabOpen`、`menuUp`）で表す（[tokens.ts:1693-1697](../../lib/tokens.ts#L1693-L1697)）。保存される文書にエディタの表示状態が混ざらないためである。新しい一時状態を足すときも同じ形にする必要がある。 <!-- b_wwvq5p75 -->

> [!IMPORTANT]
> - **選んだ日付や時刻は保存せず、ピッカーは常に今日と今を示す。** 古いスケッチにあった `day`、`hour`、`minute` は書き戻さず捨てる（[tokens.ts:674-677](../../lib/tokens.ts#L674-L677)）。ピッカーの日時を持たせる変更はこの方針に反する。 <!-- b_5nzb719g -->

> [!IMPORTANT]
> - **Next.js の規約を前提にせず、同梱ドキュメントを先に読む運用にした。** このバージョンは API や構成が既知のものと異なるため、コードを書く前に `node_modules/next/dist/docs/` を読むよう指示している（[AGENTS.md:3-5](../../AGENTS.md#L3-L5)）。`CLAUDE.md` は `AGENTS.md` を取り込むだけである（[CLAUDE.md:1](../../CLAUDE.md#L1)）。 <!-- b_0emkjqv4 -->
