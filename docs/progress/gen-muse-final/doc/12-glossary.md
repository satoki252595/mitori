# 12. 用語集 <!-- b_dqadgh9w -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| Crit | くりっと | — | エージェントと連携して出力を確認するツールである。`crit` コマンドと Web UI から利用する。 |
| Comment | こめんと | — | レビュー対象への指摘を表す概念である。`Comment` 型と `crit comment` で扱う。 |
| Config | こんふぃぐ | — | `Config` 型で表し、`crit config` と `/api/config` で扱う。 |
| Share | しぇあ | — | 公開機能であり、`crit share` と `/api/share` で扱う。`crit unpublish` で取り消す。 |
| Story mode | すとーりーもーど | — | `crit story` で起動する利用形態である。 |
| Session | せっしょん | — | Crit の作業単位を表す概念である。`Session` 型と `/api/session` で扱う。 |
| Plan | ぷらん | — | `crit plan` と `crit plan-hook` で扱うエージェントの計画である。 |
| Preview | ぷれびゅー | — | `crit preview` と `/preview` で提供される確認機能である。 |
| Live mode | らいぶもーど | — | 利用形態の一つであり、`crit live` と `/live` で提供される。 |
| Review cycle | れびゅーさいくる | — | `crit review` と `/api/review-cycle` で扱う概念である。 |
