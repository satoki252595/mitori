# 12. 用語集 <!-- b_vtnvptq7 -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| アイコン | あいこん | Icon | Material Symbols から選ぶ絵文字である。 |
| Item | あいてむ | — | 画布上の単一部品を表す型である。種類や属性と振る舞いを持ち、部品群に属する。 |
| アクション | あくしょん | Action | 跳び先や外部開きなどの振る舞い指定である。 |
| インスペクタ | いんすぺくた | Inspector | 選択中の部品や画面の属性を編集する右ペインである。 |
| 画面枠 | がめんわく | Frame | 一画面の領域である。位置と寸法と名を持ち、部品群の配置範囲を定める。 |
| 共有引数 | きょうゆうひきすう | Share parameter | 共有リンクが文書を運ぶ URL 引数名である。 |
| 形状点列 | けいじょうてんれつ | Shape points | 輪郭を等点数で並べた座標列である。 |
| 携帯検査面 | けいたいけんさめん | Mobile inspector | 小画面用の属性編集シートである。 |
| 指示文 | しじぶん | Prompt | スケッチから作る受け渡し用の実装指示文章である。 |
| スナップショット | すなっぷしょっと | Snapshot | 取消段の記録である。群と枠と全置換時の残部を持つ。 |
| スプリング | すぷりんぐ | Spring | 剛性と減衰で追従を滑らかにする模型である。 |
| 静的表示 | せいてきひょうじ | Static view | 対話状態を持たない見本描画である。 |
| タブ | たぶ | Tab | デザインと振る舞いの切り替えである。 |
| 追加行 | ついかぎょう | Prompt option | 受け渡し文末に足す選択式の条件行である。 |
| 手直し文 | てなおしぶん | Manual prompt | 利用者が直書きした指示文である。再生成より優先される。 |
| Theme | てーま | — | 明暗と対比と形状と書体と動きの指定である。 |
| バリアント | ばりあんと | Variant | 同じ部品の見た目の種別である。 |
| パレット | ぱれっと | Palette | M3 の色役割を集めた束である。画面と部品の色調を定める。 |
| 表示言語 | ひょうじげんご | Display language | 画面文言と指示文の出力言語である。 |
| 部品群 | ぶひんぐん | Group | 一体で動く部品の集まりである。軸に沿って並び、ロックを持てる。 |
| 文書 | ぶんしょ | Doc | 設計全体の保存単位である。画面枠と部品群と全体設定を持ち、保存や共有の対象になる。 |
| 補間 | ほかん | Interpolation | 前後形状の間を線形に埋める計算である。 |
| 見出し | みだし | Prompt mark | 指示文内の節と画面の位置を示す目印である。 |
| リップル | りっぷる | Ripple | 押下点から広がる光の応答である。 |
