# 12. 用語集 <!-- b_0xe8fadv -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| IconPicker | あいこんぴっかー | — | アイコン名を選ぶための選択 UI である。一覧から名前を選び、`Item` の図柄に反映する。 |
| Item | あいてむ | — | キャンバス上の単一部品を表すデータである。`Kind` と `Variant` と位置や操作設定を持ち、描画と編集の最小単位になる。 |
| Inspector | いんすぺくたー | — | 選択中の `Item` や `Frame` を編集するパネルの総称である。形状や動作や注記の変更点を集める。 |
| AI 設定 | えーあいせってい | AiSettings | 接続先とモデルと鍵の組である。`loadAiSettings` で読み込み、文章案の生成に使う。 |
| Kind | かいんど | — | ボタンやカードなど部品の種別を表す識別子である。描画内容と編集項目の切り替え基準になる。 |
| カードステージ | かーどすてーじ | CardStage | カード画像の位置を直接操作する編集面である。`CardStage` がつまみ操作で配置を変更する。 |
| 共有リンク | きょうゆうりんく | share link | `shareable` で縮約し `shareLink` で符号化した復元可能な URL である。ハッシュから `Doc` を復元できる。 |
| Group | ぐるーぷ | — | 複数の `Item` を一方向に並べた配置単位である。枠内での整列やレール表示の対象になる。 |
| 言語 | げんご | Lang | 表示言語の 4 値である。`ja` と `en` と `zh` と `ko` を切り替え、既定文言の翻訳に使う。 |
| TidyState | たいでぃーすてーと | — | 整頓ボタンの 3 状態を表す。配置の前後で押下可否と表示を切り替える。 |
| Theme | てーま | — | 暗さや対比や形状など全体の見た目設定である。`Palette` の選択と字体や角丸の指定を束ねる。 |
| Trigger | とりがー | — | タップ時の動作の起点となる設定である。遷移先の `Frame` や表示切替の条件を指定する。 |
| Doc | どっく | — | 編集対象全体を表す文書である。`groups` と `frames` と表題を持ち、保存や共有やプロンプト生成の単位になる。 |
| Variant | ばりあんと | — | 塗りや線など部品外観の変種である。同じ `Kind` 内で見た目の選択肢を切り替える。 |
| Palette | ぱれっと | — | 色トークンの束で見た目の基準になる。`schemeFromSeed` が種色から生成し、明暗と対比の切り替えに従う。 |
| パレットトークン | ぱれっととーくん | ColorToken | 配色方案から引く単一の色指定である。`Palette` 内の役割名で参照し、部品の塗りや線に使う。 |
| Frame | ふれーむ | — | モバイルやデスクトップの一画面を表す枠である。位置や寸法とプリセットを持ち、`groups` の配置範囲を決める。 |
| プロジェクトファイル | ぷろじぇくとふぁいる | project file | `isProject` で確かめ `saveProject` で保存する JSON 文書である。`Doc` をそのまま保持し、読込で復元できる。 |
| プロバイダー | ぷろばいだー | Provider | モデルの提供先種別である。`claude` や `openai` など 4 値があり、接続先と既定モデルを決める。 |
| プロンプト | ぷろんぷと | prompt | `Doc` から `buildPrompt` が作る実装依頼文である。画面構成と部品指定を含み、モデルに渡す。 |
| プロンプトオプション | ぷろんぷとおぷしょん | PromptOption | プロンプトに付ける追加行の選択肢である。`promptOptionsOf` が `Doc` から有効な一覧を整える。 |
| プロンプトマーク | ぷろんぷとまーく | PromptMark | プロンプト文中の見出し位置を示す目印である。`promptMarks` が章と画面の対応付けに使う。 |
| ボトムシート | ぼとむしーと | BottomSheet | 画面下部から出るモバイル用編集面である。小画面での検査や設定の操作面として使う。 |
| モーフィング | もーふぃんぐ | morphing | 複数形状間を点列補間で変形させる手法である。`morphedShape` が読込表示の変化に使う。 |
| リップル | りっぷる | Ripple | 押下点から広がる円形の反応表示である。`Ripple` の一覧で管理し、押下位置の応答を表す。 |
