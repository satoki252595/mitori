# 12. 用語集 <!-- b_17q7w714 -->

| 用語 | よみ | 英語 | 説明 |
|---|---|---|---|
| act-head 評価 | あくとへっどひょうか | act-head evaluation | act 確率と正解ラベル付き判定を照合する診断である。 |
| ウォームアップ | うぉーむあっぷ | warm-up | compile 有効時に runtime と device の初期化後に事前実行することである。 |
| FX カウンター | えふえっくすかうんたー | FX counter | Dynamo と Inductor のキャッシュ再利用を示す計数である。 |
| ONNX | おんっくす | — | 学習済みモデルを運ぶ交換形式である。 |
| 型付き質問 | かたつきしつもん | typed questions | choice と score と noul の 3 形式の問いである。型ごとに判定方法が決まる。 |
| guardrail | がーどれーる | — | 入力の安全性を検査し違反を遮断する仕組みである。 |
| 棄却 | ききゃく | abstention | 低確信度の回答を返さない判断である。信頼度が閾値を下回るときに起きる。 |
| questions | くえすちょんず | — | state への問い合わせの集まりである。辞書形式で複数問を一括指定する。 |
| criteria | くらいてりあ | — | 候補名から説明文への写像である。選択肢の意味を与える。 |
| 較正 | こうせい | calibration | 確信度の値を実際の正答率に合わせる温度調整である。 |
| 構造化決定 | こうぞうかけってい | structured decision | スキーマから質問を起こして値を決める手続きである。JSON Schema や Pydantic から生成する。 |
| コールドスタート | こーるどすたーと | cold start | 新規ディレクトリーで始める測定条件である。 |
| ゴールデン | ごーるでん | golden | 期待出力を固定した照合用ファイルである。移植実装の一致確認に使う。 |
| 質問型 | しつもんがた | question type | 選択と採点と肯定否定から成る問いの種類である。choice と score と noul に対応する。 |
| 絞り込み | しぼりこみ | shortlist | 多肢選択を上位候補に減らしてから判定する工夫である。埋め込み類似度で k 件に絞る。 |
| 指紋 | しもん | fingerprint | 質問集合の同一性を示す要約値である。 |
| 信頼度 | しんらいど | confidence | 回答の確からしさの指標である。確信度とも呼ぶ。 |
| 推論 | すいろん | inference | 状態と質問から回答を計算する処理である。 |
| 推論器 | すいろんき | Agent | 状態と質問から回答を返す実行主体である。Agent が担う。 |
| スイート | すいーと | suite | 関連する評価ケースを束ねた組である。 |
| stamp | すたんぷ | — | 再生成の正当性を示す印である。 |
| state | すてーと | — | 判定対象の文や記録である。予測では質問と組で渡す。 |
| state_key | すてーときー | — | 入力から判定対象を取り出すキーや関数である。 |
| selector | せれくたー | — | クエリに適したツールを選ぶコンポーネントである。 |
| checkpoint | ちぇっくぽいんと | — | 学習済み重みと設定をまとめた保存単位である。書き出しや読込みの対象となる。 |
| choice | ちょいす | — | 複数候補から一つを選ぶ質問型である。criteria で選択肢の意味を与える。 |
| hub キャッシュ | はぶきゃっしゅ | hub cache | HF_HUB_CACHE または HF_HOME 配下の保存先である。 |
| バックエンド | ばっくえんど | backend | 符号化器と頭部の実行を隠す接合部である。既定や高速化などの実行形態を表す。 |
| 被覆率 | ひふくりつ | coverage | 確信度順に残した事例の割合である。棄却後の残存率を示す。 |
| フィクスチャ | ふぃくすちゃ | fixture | 移植実装の一致確認に使う固定の入力と期待値である。 |
| フォワードパス | ふぉわーどぱす | forward pass | 入力を 1 回符号化して全質問に答える計算である。 |
| fallback | ふぉーるばっく | — | 信頼度不足時に選ぶ既定の経路や担当者である。 |
| フック | ふっく | hook | 予測の前後に呼ばれる観測処理である。 |
| 振分 | ふりわけ | dispatch | 言語や質問から機種を選ぶ判断である。Router の中心機能である。 |
| 分離グラフ | ぶんりぐらふ | split graph | encoder と head を別ファイルに分けた ONNX グラフである。 |
| preset | ぷりせっと | — | 用途別に組立済みの質問集である。triage や guard などを一括指定する。 |
| predict | ぷれでくと | — | 選定後に全問へ答える操作である。1 回の実行で全質問の回答を返す。 |
| 変異評価 | へんいひょうか | metamorphic evaluation | 選択肢の順序や文面を変えて予測の安定性をみる手法である。 |
| ベンチマーク | べんちまーく | benchmark | 精度や速度を比べるための定型の測定実行である。 |
| min_confidence | みんこんふいでんす | — | 低信頼回答を棄却する閾値である。 |
| 融合グラフ | ゆうごうぐらふ | fused graph | 符号化器と判定部を 1 ファイルにまとめた ONNX グラフである。 |
| RemoteRouter | りもーとるーたー | — | 遠隔呼び出しで同形を保つ選定器である。HTTP 経由で Router と同じ操作を提供する。 |
| Router | るーたー | — | 担当モデルを選び予測を束ねる中心である。言語や質問から適した担当を選定する。 |
| routing | るーてぃんぐ | — | どの担当が答えたかの記録である。予測結果に付随する。 |
| RouteDecision | るーとでしじょん | — | 選定結果を表す辞書である。選ばれた model と reason を持つ。 |
