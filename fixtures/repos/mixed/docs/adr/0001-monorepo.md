# ADR 0001: 1 つのリポジトリで 4 つの言語を扱う

- 状態: 採用

## 背景

画面（TypeScript）、API（Go）、レポート（Python）、検索インデックス（Rust）は同じ ISBN の語彙を共有している。
リポジトリを分けると、ISBN の正規化を変えるたびに 4 か所へ PR が要る。

## 決定

1 つのリポジトリに置き、`nix develop` で全言語のツールを揃える。CI は `just test` だけを呼ぶ。

## 結果

- 言語をまたぐ変更が 1 つの PR で済む。
- CI の所要時間は最も遅い言語に引きずられるので、将来は変更されたディレクトリだけを流す。
