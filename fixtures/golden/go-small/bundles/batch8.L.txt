1|# tsundoku (Go)
2|
3|積読（買ったけれどまだ読んでいない本）を管理する小さな HTTP サービスと CLI。標準ライブラリだけで動く。
4|
5|## 動かす
6|
7|```sh
8|make build
9|./bin/tsundoku serve -port 8080
10|curl localhost:8080/api/books
11|```
12|
13|| 変数 | 既定値 | 意味 |
14||---|---|---|
15|| `PORT` | `8080` | 待ち受けポート |
16|| `DATABASE_URL` | なし | 将来の SQL ストア用（未設定ならメモリ） |
17|| `LOG_LEVEL` | `info` | ログの詳しさ |
18|| `TSUNDOKU_API_TOKEN` | なし | 設定すると書き込み系 API に Bearer トークンを要求する |
19|
20|## API
21|
22|| メソッド・パス | 説明 |
23||---|---|
24|| `GET /api/books` | 一覧 |
25|| `GET /api/books/{id}` | 1 冊 |
26|| `POST /api/books` | 追加。title が無ければ ISBN から取得する |
27|| `DELETE /api/books/{id}` | 削除。存在しない id は 404 |
28|| `/healthz` | 死活監視 |
29|
30|## 構成
31|
32|- `cmd/tsundoku` — CLI（標準の `flag`）
33|- `internal/server` — HTTP ハンドラ
34|- `internal/store` — 永続化のポートとメモリ実装
35|- `internal/meta` — ISBN からのメタデータ取得
36|- `migrations` — SQL ストア用のスキーマ
37|
38|テスト: `make test`。整形: `make fmt`。静的検査: `make lint`。

1|# ADR 0001: HTTP には net/http を使う
2|
3|- 状態: 採用
4|- 日付: 2026-01-01
5|
6|## 背景
7|
8|tsundoku の API は 5 本のルートしかなく、外部依存を増やす理由が弱い。Go 1.22 以降の `http.ServeMux` は
9|メソッドとパスパラメータ（`GET /api/books/{id}`）を扱える。
10|
11|## 決定
12|
13|ルーティングは標準の `net/http` で行う。chi と cobra は `//go:build ignore` の下書き（`internal/server/chi_routes.go`、
14|`cmd/tsundoku-cobra`）に置き、依存を入れる判断は v2 API を作るときに行う。
15|
16|## 結果
17|
18|- ビルドとテストにネットワークも `go mod download` も要らない。
19|- ミドルウェアは自前の薄い層（トークン検査）で足りる間はそのままにする。
20|- 外部リクエストのタイムアウトは `internal/meta` の 10 秒に統一する。
